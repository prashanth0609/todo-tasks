# todo-tasks
A responsive and interactive To-Do List web application built using HTML, CSS, and JavaScript. This project helps users manage daily tasks efficiently with features like adding, deleting, and marking tasks as completed. Designed with a clean user interface and mobile-friendly layout for a smooth user experience across all devices.
Built with a focus on responsive web design and smooth user experience, the application works efficiently across desktop, tablet, and mobile devices.
Key Features
Add and manage daily tasks
Mark tasks as completed
Delete tasks instantly
Responsive and mobile-friendly design
Clean and modern user interface
Smooth user interaction and DOM manipulation
Lightweight and fast performance
Technologies Used
HTML5
CSS3
JavaScript (DOM Manipulation)
Project Highlights
Developed using core front-end technologies
Focused on responsive UI/UX principles
Beginner-friendly yet professionally structured
Demonstrates practical JavaScript functionality
